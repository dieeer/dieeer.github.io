Support

Having trouble with automatron? Here are the most common fixes and how to get help.

Spotify won't connect

Make sure you have an active Spotify account. automatron uses Spotify's recently played API, which requires a Spotify Free or Premium account. If the login screen doesn't load, check your internet connection and try again.

Wallpaper isn't saving

automatron needs photo library permission to save wallpapers. Go to Settings > automatron > Photos and make sure access is enabled. The app only requests add-only access.

Shortcut not appearing

The "Generate Wallpaper" action registers automatically when you open the app. If it doesn't appear in Shortcuts, try opening automatron once, then search for "automatron" in the Shortcuts app.

Premium not restoring

Tap "Restore Purchases" in Settings. Make sure you're signed into the same Apple ID used for the original purchase. It may take a moment for StoreKit to verify.

Still need help?

Open an issue on GitHub and we'll get back to you.
